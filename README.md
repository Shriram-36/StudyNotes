# 📚 StudyNest – Smart Study Management System

StudyNest is a modern, student-focused study management platform designed to help students organize their academic subjects, units, topics, notes, attachments, and learning progress in one place.

The platform provides a clean workspace where students can manage their syllabus and study materials while tracking their overall academic progress.

## ✨ Features

### 📖 Subject Management

* Add and manage multiple subjects.
* Quickly switch between subjects.
* View subject-wise learning progress.

### 🗂️ Unit & Topic Organization

* Divide subjects into multiple units.
* Add topics under each unit.
* Mark completed topics.
* Track progress based on completed concepts.

### 📝 Rich Notes Editor

* Create and edit notes for individual topics.
* Support for headings, bold, italic, underline, lists, and code blocks.
* Organize important concepts in a structured format.

### 📎 Attachments

* Attach study materials and reference files to topics.
* Keep important resources connected with the relevant concept.

### 🏷️ Topic Tags

* Add tags such as `Very Important`, `Important`, and custom sub-concepts.
* Quickly identify high-priority topics for examination preparation.

### 📊 Progress Tracking

* Track overall study progress.
* View completed and pending topics.
* Monitor subject-wise and unit-wise progress.

### 💾 Auto Save

* Automatically save changes while editing notes.
* Display the current save status to prevent accidental data loss.

## 🎯 Problem Statement

Students often keep their syllabus, handwritten notes, PDFs, screenshots, and important topics across different applications.

StudyNest solves this problem by providing a centralized academic workspace where students can organize their entire syllabus and study material in a structured manner.

## 🚀 Main Workflow

```text
Add Subject
     ↓
Create Units
     ↓
Add Topics
     ↓
Create Study Notes
     ↓
Attach Resources
     ↓
Mark Topics Complete
     ↓
Track Overall Progress
```

## 🖥️ Dashboard

The StudyNest interface consists of:

* **Sidebar** – Displays all available subjects.
* **Units Panel** – Displays units within the selected subject.
* **Topics Panel** – Displays topics belonging to the selected unit.
* **Notes Editor** – Allows students to create and edit detailed notes.
* **Progress Indicator** – Shows overall learning progress.

## 📚 Example

A student studying **DAA (Design and Analysis of Algorithms)** can organize their syllabus as:

```text
DAA
│
├── Unit 1
│   ├── Recurrence Relation
│   ├── Master's Theorem
│   └── Asymptotic Analysis
│
├── Unit 2
│   ├── Divide and Conquer
│   ├── Binary Search
│   └── Merge Sort
│
└── Unit 3
    ├── Greedy Algorithms
    ├── Dynamic Programming
    └── Backtracking
```

Each topic can contain detailed notes, important tags, and attachments.

## 🎨 Design

StudyNest follows a modern dark-themed interface focused on simplicity and productivity.

Key design principles:

* Clean and distraction-free interface
* Dark mode
* Clear navigation
* Color-coded subjects
* Minimal and modern components
* Easy-to-read study content
* Progress-oriented UI


## 👨‍💻 Purpose

StudyNest is designed to make academic preparation more organized, efficient, and measurable by bringing syllabus management, notes, resources, and progress tracking into a single platform.
